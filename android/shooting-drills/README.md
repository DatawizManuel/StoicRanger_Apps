# Stoic Ranger - Shooting Drills (Android)

Shown as **SR_Shooting Drills** under the launcher icon (Stoic Ranger emblem on coyote brown; Gun Database black,
Training Log olive). Package id `at.stoicranger.shootingdrills`. Offline, metric, data stays on the phone.
Same look and architecture as the other two Stoic Ranger apps.

- **Drills**: library of 173 drills in 8 groups (pistol / rifle × static / dynamic × timed / not timed), each
  tagged live fire, dry fire or both. Filters Gun, Fire (live / dry), Motion, Timer, level, favourites and search
  (remembered; any combination, or none). *Clear selection* resets all filters. Search also finds common names
  ("Mozambique", "box drill") and keywords ("malfunction", "weapon handling", "1 to 5"). Static = the shooter does
  not move and handles the gun little (no holster draw, no reloads).
- **Drill page (one-pager)**: tags, goal, distance, rounds, par time, target, range setup diagram (drawn from the
  drill's text, top view), steps, standard, dry-fire version, credit, safety, results with best result.
  *Print target* prints the matching printable; *Print this drill* gives an A4 one-pager (print or Save as PDF).
- **Printables**: 13 own target designs (body zone, head zone, 10-dot sheet with SR dot sequence, 25-dot sheet,
  bullseye, zero grid, rifle dot ladder, numbered shapes, tall target, dry-fire plates for 10 m, dry-fire pistol
  targets for 3 m, shot plot & data card, drill score log). Plain geometric shapes, no copied target faces, the
  Stoic Ranger emblem and a 100 mm check bar on every sheet. Print A4 at 100 %.
- **Results**: per drill: date, live / dry, training (when linked with the Training Log), shooter, gun, time s,
  hits / shots, points, distance, standard met, notes. Home shows drill of the day, library overview, favourites and recent results. *New* opens: log a result,
  drill of the day, random drill (from the current filter), add shooter, add gun.
- **More**: shooters and guns, backup save / share / restore, one-off import of shooters and guns from a Gun
  Database or Training Log backup, light / dark / follow phone.

## Install the test build

1. Copy `sr-shooting-drills-0.2.0-debug.apk` to the phone and open it in the Files app; allow installs from that app.
2. Play Protect may warn about an unknown app: *Install anyway* (debug build signed with the test key).
3. Open **SR_Shooting Drills** and tap *Open the drill library*.

Updating: install a newer APK over the old one; the data is kept (see `MIGRATIONS.md`).

## Link with Stoic Ranger - Training Log (from 0.2.0)

Switch on in **both** apps: here *More › Link with Training Log*, there *More › Stoic Ranger apps* (needs a Training
Log version with the Shooting Drills link; until then the status line says the Training Log is too old).

- Shooters and guns come from the Training Log (enter them once, there). The first sync matches existing entries by
  name; after that by the Training Log id (`source: {app:'training-log', id, uid}`). Name, status, type, caliber and
  zero distance are edited there; notes stay local.
- Logging a result: the app asks the Training Log for trainings on the chosen date. One training that day is picked
  automatically, several can be chosen from, and the shooter is taken from the training if none is set. The result
  stores `training: {app, id, uid, date, label}`.
- Sync runs at start, when the app comes back to the front and with *Sync now*. Switching off in either app keeps
  everything here as a local copy (training links included). Without the Training Log or without consent, this app
  works on its own.
- How: same signing key (cert SHA-256 0C:F0:92:51:…), signature permission `at.stoicranger.permission.LINK`; this app
  calls the Training Log's provider `at.stoicranger.traininglog.link` (`.debug.link` for Gradle debug builds) with
  `status`, `shared` and `trainings {date}`. Nothing leaves the phone.

## Drill library

App content, not user data: `app/src/main/assets/www/js/drills-data.js`, generated by `tools/make_drills.py`
from `research/drills.json` (made by `research/build_drills.py`). **Drill ids (`pst-01` …) are permanent**:
results refer to them. Never renumber or reuse an id; new drills are appended to their group with new ids. Names may
change (0.2.0 renamed six drills to their common names), ids never.

## Build

**Android Studio / Gradle:** open this folder, `./gradlew assembleDebug`. No AndroidX or third-party Android dependencies.

**Without the SDK manager (cloud):** `tools/build-debug.sh` (aapt2, ecj, d8, apksigner against an API 34
`android.jar` in `$TOOLS`). Keep `debug.keystore`: it is the same key as the other Stoic Ranger test builds.

Before each release: `node tools/test-data-safety.js` must print only PASS.
All printables as one PDF for a PC printer: `node tools/export-printables.js sr-printables.pdf`.
